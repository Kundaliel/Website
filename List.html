Server Ranks & Roles

Basic Ranks

  1. Guest – Can chat, look around, and explore but cannot build or interact.
  2. Recruit – Can place/break blocks in designated areas, use basic commands.
  3. Member – Full building rights, can use /tpa, /home, and economy commands.
  4. Trainee – Limited staff training rank; can mute/warn but not ban.
  5. Jr. Trainee – Can assist with moderation, access to staff chat.
  6. Sr. Trainee – Can kick, basic punishments, and access to staff tools.

Creative & Technical Roles

  1. Builder – Extra WorldEdit permissions, access to creative mode in build areas.
  2. Artist – Can use map art tools, armor stand editors, and pixel art features.

Prestige & Donor Ranks

Perks:

  • Access to /chatgradient

ENGINEER RANK - €19.99

Perks:

  • Ability to change rank prefix twice per month

CREATOR RANK - €34.99

Perks:

  • Access to all premium cosmetics

  • Access to 10 plots in Plots

Moderation Team

  1. Jr. Mod – Can mute, warn, and moderate chat.
  2. Mod – Can kick, tempban, and rollback minor griefs.
  3. Sr. Mod – Full ban powers, region protection, and moderate grief rollback.
  4. Head Mod – Leads moderators, can assign temp staff roles.

Community & Event Staff

  1. Supporter – Helps answer player questions, access to /helpop.
  2. Community Manager – Manages Discord/forums, promotes events.
  3. Event Coordinator – Can create events, use /broadcast for announcements.

Administration & Development

  1. Jr. Admin – Can manage staff, assist with server settings.
  2. Admin – Manages permissions, server rules, major grief rollbacks.
  3. Sr. Admin – Has near full control over server management.
  4. Head Admin – Oversees all admins, final say on bans and appeals.

High-Level & Technical Staff

  1. Manager – Handles applications, promotions, and overall staff operations.
  2. Developer – Access to plugin files, can reload/restart the server.
  3. System Admin – Full FTP access, database control, backend maintenance.

Server Leadership

  1. Co-Owner – Shares owner permissions, handles major decisions.
  2. Owner – Full control over everything.
  3. Founder – The original creator, holds honorary authority.
